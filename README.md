# WillianaPortifolio

Portfólio pessoal de Williana — site estático em HTML, CSS e JavaScript.

## Estrutura

```
WillianaPortifolio/
├── index.html      # Página principal
├── css/
│   └── style.css   # Estilos do site
├── js/
│   └── script.js   # Interações (menu, rolagem suave)
└── assets/         # Imagens e outros arquivos
```

## Como visualizar

Basta abrir o arquivo `index.html` no navegador, ou publicar via GitHub Pages:

1. Vá em **Settings → Pages** no repositório
2. Em **Source**, escolha a branch `main` e a pasta `/ (root)`
3. Salve — o site ficará disponível em `https://kelvyncode.github.io/WillianaPortifolio/`
